NumPy Mini Project — Student Data Analysis 📊

A beginner-friendly NumPy mini project created to practice and demonstrate the core concepts of NumPy, including array creation, indexing, slicing, reshaping, mathematical operations, aggregation functions, and basic statistical analysis.

This project is part of my journey toward learning Python, Data Science, and Machine Learning.

📌 Project Overview

In this project, NumPy is used to create and analyze a small student dataset.

The project demonstrates how numerical data can be efficiently stored, manipulated, and analyzed using NumPy arrays.

What this project covers:
NumPy array creation
Array dimensions and shapes
Indexing and slicing
Reshaping arrays
Array data types
Mathematical operations
Aggregation functions
Statistical calculations
Boolean indexing
Basic data analysis using NumPy

Why NumPy?

NumPy is one of the fundamental libraries of the Python Data Science ecosystem.

It provides powerful tools for:

Numerical computing
Array manipulation
Mathematical operations
Statistical analysis
Scientific computing
Machine Learning preprocessing

NumPy also provides efficient vectorized operations, which are generally much faster and more convenient than manually processing numerical data using Python loops.
